# 漢字ペディア 下つきリンク補完

漢字ペディアの漢字個別ページにある「下つき」の語を、既存の言葉項目へリンクするChrome拡張です。語と読み仮名を含む全体をクリックできます。配布先はGitHubのみです。

## 導入

1. [GitHubリポジトリ](https://github.com/linked34ce/kanjipedia-extension)の「Code」→「Download ZIP」からダウンロードし、ZIPを展開する。
2. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダー内の `extension` フォルダーを選ぶ。
4. 漢字ペディアの漢字個別ページを開く。すでに開いている場合はページを更新する。

読み込み用ファイルと対応表は同梱しています。導入時にNode.jsやデータ収集の実行は不要です。ソースを変更して利用する場合は、[開発・ビルド手順](docs/development.md)を参照してください。

## 使い方

インストール後は自動で動作し、設定やボタン操作は不要です。

- 「下つき」の淡い青色でハイライトされた語をクリックすると、対応する言葉項目へ同じタブで移動します。
- キーボードではTabキーでリンクを選び、Enterキーで開けます。
- ホバー時やキーボードで選択したときは、背景が少し濃くなります。

たとえば[亜のページ](https://www.kanjipedia.jp/kanji/0000000500)では、対応データがある場合に `白亜(ハクア)` 全体がリンクになります。

## 仕様

- 対象は `https://www.kanjipedia.jp/kanji/` 以下の漢字個別ページにある「下つき」です。
- 同梱データと語・読み仮名が一致し、リンク先が一意に決まる場合だけリンクを補完します。読み仮名がない場合も、リンク先を一意に決められる語だけ補完します。
- 未対応の語、読みが一致しない語、候補が曖昧な語は原文のまま表示します。リンクがないことは、辞典に項目が存在しないことを意味しません。
- リンクには読み仮名と括弧も含めます。元の漢字・仮名・括弧の表記、中点、周囲の余白を保ちます。
- 「下つき」のリンクを淡い青色の背景と控えめな下線で示します。既存の下つきリンクにも同じ装飾を適用します。
- 他の欄は変更せず、既存のリンクを重複して作りません。
- 実行中の検索・外部データ取得・閲覧履歴の送信は行いません。

## 更新の反映

拡張のファイルを更新したら、`chrome://extensions` でこの拡張の再読み込みボタンを押し、対象ページを更新してください。

## 無効化・削除

`chrome://extensions` でこの拡張のスイッチをオフにすると無効化できます。「削除」を押すとアンインストールできます。変更後は対象ページを更新してください。
